# ССГ · Экотехнопарк Липецкого района

Сайт Экотехнопарка: обращение с отходами, процесс сортировки, показатели работы,
контакты, интерактивный квиз и памятка для печати.

**Сайт:** https://ekotechnopark.vercel.app/

Статический HTML, CSS и JavaScript. Серверная часть и npm-зависимости не требуются.
Шрифты Inter и библиотеки GSAP / ScrollTrigger находятся в `assets/`.

## Локальный запуск

Нужен Python 3. Из корня проекта:

```bash
python -m http.server 8765 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8765/. Для корректной работы видео и квиза запускайте сайт
через HTTP, а не двойным кликом по HTML-файлу.

## Сборка для публикации

```bash
python deploy/build.py ekotechnopark.vercel.app
```

Для другого хостинга передайте его домен без `https://` и слешей.
Готовый сайт появится в `_deploy/site`. Скрипт копирует только файлы сайта,
создаёт `robots.txt` и `sitemap.xml`, добавляет версии CSS/JS для обновления кэша
и проверяет пути с учётом регистра, кадры анимации и изображения категорий.
При каждой сборке содержимое `_deploy/site` заменяется.

На Vercel публикуйте готовую папку `_deploy/site` в существующий проект
`ekotechnopark`; на Apache загрузите её содержимое в корень сайта вместе с `.htaccess`.
Настройки аккаунта и привязка Vercel хранятся локально и в репозиторий не входят.

## Проверка квиза

При запущенном локальном сервере, в PowerShell с установленным `agent-browser`:

```powershell
./deploy/check-dog-motion.ps1 -BaseUrl http://127.0.0.1:8765
```

Проверяются четыре состояния маскота на мобильной и десктопной ширине:
ролики воспроизводятся, контейнер остаётся неподвижным.

## Обновление контента

Тексты, показатели и контакты находятся в HTML. Для дробных счётчиков укажите
`data-count` с десятичной точкой и `data-decimals="2"`; посетителю показывается
число с запятой. Показатели за январь–октябрь 2026 года: на обработку поступило
160 928,96 т, на утилизацию направлено 67 364,95 т.

Видео первого экрана — `assets/video/ecotechnopark-tour-2026-11-08.mp4`.
При замене используйте новое имя файла и обновляйте `data-src` в `index.html`,
чтобы браузер не показывал старую версию из кэша. Видео воспроизводится без звука,
приостанавливается вне экрана; при уменьшении движения показывается фотография.

Архивы разработки, исходные фото и видео, внутренние документы и локальные
настройки инструментов в публичный репозиторий не включены.
